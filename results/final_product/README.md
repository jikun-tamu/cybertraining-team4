# Final Product — LA Fire 2025 Building Damage Assessment

Committed copies of the pipeline's final deliverable (generated by
`pipeline/scripts/analysis/build_combined_dataset.py`, product v3 of 2026-10-03: stage1 v0.2
footprints (tiled SAM 3 with cross-window instance merging, threshold 0.4) and Stage 2b retrained
on all ten xView2 tier1 events):

- `building_damage_all_cells.csv` — 22,024 building instances in 126 of 295 cells, one row each:
  M1/M2b damage class + probabilities, per-date quality counts, Stage 2a
  type/population, SAM3 confidence, WGS84 + UTM geometry columns
- `building_damage_all_cells.gpkg` — same data as GeoPackage (open directly in QGIS)

Canonical location (with the additional `.geojson` variant, redundant with the gpkg):
`/media/data/building_instance_tamu/la_fire_2025/stage2_damage/multidate_full_run_v3/`.
The April 2026 product (21,797 instances, fragmented by the old tile stitching) is in git
history (commit `0dc7630`); its run directory was deleted 2026-10-02. See
`reports/sam3_audit_2026-09.md` §5.

**Validation** (CAL FIRE DINS and LA County footprints; `reports/sam3_audit_2026-09.md` §6–9):
M2b destroyed vs not destroyed, P 0.964 / R 0.952 / F1 0.958 on 9,168 detected buildings with
valid imagery; end to end, counting the 18% of destroyed buildings Stage 1 misses, P 0.964 /
R 0.779 / F1 0.862. Minor and major classes are rare in both the training data and DINS and are
not validated. M2b class counts: 14,486 no damage, 122 minor, 370 major, 5,748 destroyed,
1,298 unknown (no valid post-fire coverage).
